# DecodeLabs Project 1 – Data Cleaning and Preparation

## Project Overview

This project was completed as part of the DecodeLabs Data Analyst Internship. The objective of the project was to clean and prepare the provided dataset for further analysis.

## Dataset

- Total Records: 1,200
- Total Columns: 14

## Data Cleaning Performed

- Handled missing values in the CouponCode column.
- Replaced 309 missing CouponCode values with "No Coupon".
- Checked OrderID for duplicate records.
- Verified that there were no duplicate OrderIDs.
- Validated date fields.
- Checked numeric fields for valid values.
- Reviewed text and categorical fields for consistency.
- Validated TotalPrice calculations.

## Final Result

The dataset was successfully cleaned and validated. The final dataset contains 1,200 records and 14 columns and is ready for further analysis.
